# Bina Binary (Demo)

A simulated Matches/Differs digit-trading interface built as a single-page web project.

## Features
- Live simulated price chart (1 tick per second)
- Last-digit statistics (0-9) with percentages
- Match / Differ trades on a chosen digit
- Virtual demo balance ($10,000) and virtual deposits (minimum $5)
- Win/loss tracking

## Run
Open `index.html` in any browser. No install or server needed.

## Host
Upload `index.html` to Netlify Drop, GitHub Pages, or any static host.

## Note
This is an educational simulation using virtual money and randomly generated prices. It is not a real trading platform and does not process real payments.
